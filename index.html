03
Healthcare AIPublic repository

Task-Aware ECG Classification & Denoising

A PyTorch research pipeline that uses downstream rhythm classification feedback to improve ECG denoising while protecting waveform morphology.

Built a classifier-first workflow that trains or adapts an ECG classifier, freezes it, then fine-tunes a denoiser through downstream task loss. Anchor and slope-consistency constraints discourage the denoiser from becoming a class-hacking front end.

  • Structured manifests, data splits, checkpoints and reports
  • Flexible class mappings and pretrained CNN-BiLSTM adaptation
  • MIL experiments, detailed validation and threshold calibration

Forecasting researchPublished

Wrinkles in Time

Multi-scale patching and super-resolution for efficient long-horizon time-series forecasting.

Designed a hybrid CNN-MLP framework that decomposes series into seasonal and trend components, extracts multi-scale periodic structure and reconstructs fine-grained trend information. The work balances prediction quality with computational efficiency.

  • Multi-scale 2D patching for seasonal structure
  • Super-resolution treatment of trend components
  • Reproducible implementation across public benchmarks
