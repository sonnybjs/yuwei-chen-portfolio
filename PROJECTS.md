# Project Catalogue

This catalogue separates public repositories, published research, collaborative work and private product projects. It is written for public use and does not expose employer data, credentials, private datasets or personal job-search records.

## Public repositories

### SydHah Comedy Eventbrite Operations Agent

- **Type:** Agentic AI, automation and integration
- **Status:** Working local-first system; public code
- **Repository:** <https://github.com/sonnybjs/xixiao-eventbrite-admin-agent>
- **Stack:** Python, FastAPI, Discord.py, Codex SDK, Eventbrite REST API, SQLite
- **Summary:** Converts natural-language operations requests into structured plans and confirmed Eventbrite actions. Includes allowlists, dangerous-action guards, idempotent updates, mock/live client separation, local audit logs and 20 passing unit/integration tests.
- **Boundary:** Does not claim external scale, autonomous financial operations or measured commercial impact.

### Sydney Offshore Pelagic AI Map

- **Type:** Geospatial AI and decision support
- **Status:** Full-stack prototype; public code
- **Repository:** <https://github.com/sonnybjs/sydney-offshore-pelagic-ai>
- **Stack:** Python, scikit-learn, experimental PyTorch, FastAPI, Next.js, React, TypeScript, GeoJSON
- **Summary:** Combines environmental features, bathymetry, presence-background sampling, model artefacts and interactive maps to explore relative pelagic habitat suitability around Sydney and nearby NSW waters.
- **Boundary:** Provides model exploration rather than exact fish locations, guaranteed catches, navigation advice or verified operational fishing marks.

### Wrinkles in Time

- **Type:** Deep-learning research and reproducible implementation
- **Status:** Published in *Neurocomputing*, 2026; public code
- **Repository:** <https://github.com/sonnybjs/Wrinkles-in-time>
- **Paper:** <https://doi.org/10.1016/j.neucom.2026.133021>
- **Stack:** Python, PyTorch, CNN-MLP, time-series decomposition, multi-scale patching, super-resolution
- **Summary:** A computationally efficient forecasting framework that extracts seasonal structure through multi-scale 2D patching and refines trend components through super-resolution.

## Research projects

### Fine-scale Deep Learning for Time-Series Forecasting

- **Type:** PhD research
- **Status:** Published in *Applied Intelligence*, 2024
- **Paper:** <https://doi.org/10.1007/s10489-024-05701-w>
- **Methods:** Temporal interpolation, time-series decomposition, Dynamic Time Warping, deep learning, benchmarking
- **Summary:** Developed a fine-scale representation of cyclical patterns and evaluated DTW as a training objective for shape-aware forecasting on uncertain time-series data.

### EdgeCraft: Dynamic Sparse Graph Learning

- **Type:** Spatio-temporal graph forecasting research
- **Status:** Working paper, 2026
- **Paper:** <https://ssrn.com/abstract=6497861>
- **Methods:** Graph neural networks, dynamic adjacency refinement, graph sparsification, autoregressive forecasting
- **Summary:** A no-label inference-time graph refinement method designed to adapt propagation structure under regime change and long-horizon rollout.

### Small-Object Detection with ROI Super-Resolution

- **Type:** Master's research project
- **Status:** Private research project
- **Methods:** Computer vision, small-object detection, classification, ROI feature processing, super-resolution
- **Summary:** Explored super-resolution of region-of-interest features to retain fine detail for more precise small-object detection and classification.
